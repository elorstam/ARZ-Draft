# ARZ Draft

ARZ Studio CAD is a native C++23 architectural CAD application.

## V1 Goal

Professional manual 2D CAD focused on architectural workflows.

V1 includes:

- AutoCAD-like drawing workflow
- English UI and commands
- Layer / color / linetype / lineweight system
- Blocks
- Dimensions
- Hatches
- Layouts
- Architectural area calculations
- Story / floor organization
- Parcel and coordinate tools
- Independent section tables and architectural schedules
- DXF / DWG interoperability
- PDF output

## V2 Goal

BIM features including:

- Walls
- Doors
- Windows
- Slabs
- Roofs
- Levels
- Automatic sections
- Automatic elevations
- Quantity takeoff

## Technology

- C++23
- CMake
- Qt 6
- OpenGL
- OpenCascade planned for V2
- ODA planned for production DWG interoperability
