# AutoCAD 2021 LINE Behavioral Reference

## Purpose

This document records black-box interaction observations used to guide ARZ Studio
CAD Phase 1.2.5. It contains behavioral notes only. It includes no Autodesk source
code, proprietary assets, or copied visual resources.

## Observed Workflow

1. `LINE` starts with `Specify first point:`.
2. After P1, the prompt becomes `Specify next point or [Undo]:` and a transient
   P1-to-cursor reference line appears with distance and angle input near the cursor.
3. F3 Object Snap changes the resolved provisional point and marker immediately.
4. F8 Ortho constrains provisional geometry horizontally or vertically while the
   physical cursor can remain elsewhere.
5. Accepting P2 commits P1-P2, keeps LINE active, and uses P2 as the next segment start.
6. Accepting P3 commits P2-P3; chaining continues until explicitly finished.
7. Enter or Space while awaiting another point finishes LINE and keeps committed segments.
8. Escape cancels only the unfinished portion, exits LINE, and keeps committed segments.
9. Active-command right-click opens a context menu containing Enter, Cancel, Recent
   Input, Undo, Osnap Overrides, Pan, Zoom, and QuickCalc-style actions; choosing
   Enter finishes LINE.
10. Idle Enter or Space repeats the last repeatable command.
11. Preview geometry is transient and pointer movement does not mutate the document.
12. Preview and final commit use the same resolved point source.

## ARZ Phase 1.2.5 Interpretation

ARZ adopts chained LINE segments, shared snap/Ortho point resolution, transient
rubber-band geometry, distance/angle state, finish/cancel preservation, and idle
command repeat. ARZ currently keeps direct right-click finish for active commands
instead of reproducing the full reference context menu.
